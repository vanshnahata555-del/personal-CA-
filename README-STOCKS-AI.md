# Stocks AI

Stocks AI in this build is powered by the same Google Gemini API used by Nivara AI.

The stock-study endpoint accepts a symbol/company name and asks Gemini for an educational research brief covering business model, fundamentals to study, valuation concepts, risks, governance questions, and what current information should be verified next.

This build intentionally does **not** claim to have a live market-price feed and does not use Twelve Data. Time-sensitive figures must be checked against current official exchange/company disclosures.

For a minor, Stocks AI is educational only. It must not provide personalized buy/sell/hold decisions, target prices, entry/exit instructions, allocations, or real-money execution. Paper-trading/learning exercises are supported.
